### 🚀 About Me

- 🎮 Outside of work, I build tools for the Indonesian streaming community — donation-triggered game control systems, overlays, and viewer-interaction platforms.
- 🔧 I like squeezing performance out of low-spec hardware just as much as I like designing new systems from scratch.
- 🌱 Currently exploring ESP32/IoT integrations, payment gateway tooling, and installer/packaging workflows for desktop apps.

### 🛠️ Featured Projects

| Project | Description |
|---|---|
| 🎮 **[Viewer-Merusuh](https://github.com/noobiiefun/Viewer-Merusuh)** | Donation-triggered game control system for Indonesian streamers. Built with Electron, Express, React & AutoHotkey — includes a pixel-art donor Avatar Overlay for OBS and an in-progress RC Module letting viewers control real ESP32-based RC cars via donations. |
| 💬 **NoobCRM** | Internal CRM/messaging platform on Node.js, Express, Socket.IO, SQLite & whatsapp-web.js — WhatsApp Business API broadcast templates, live GPS field-team tracking with Leaflet.js, and a contact map with geocoding. |
| 🔌 **DSN Hub Integration** | Host-to-Host integration with DSN Hub Center's Open API to power ShopeePay and pulsa top-up services for MTI. |
| 🕹️ **PS Billing** | Offline PlayStation rental billing web app with a TV overlay system — vanilla JS + localStorage, no backend required. |
| 📡 **Hey Streamer Notice Me (HSNM)** | Consolidates multiple streaming notification widgets into a single OBS Browser Source via a WebSocket-proxying Node.js server. |
| 📊 **SocialFlow** | Single-file social media management dashboard. |

> More experiments live under my other repos — including a self-service game top-up storefront (Node.js, BullMQ, Redis, Tripay/Midtrans) and a LAN-based "CoworkerRestArea" desktop-style web platform.
